# 2.0 架构清理与升级

本次清理处理协议转换与部署入口冗余。上游拒绝是独立的响应状态，仍通过 `stop_reason: refusal` 和受限 `stop_details` 交付；不能据此重构推断账号状态或拒绝原因。

## 保留一套消息表示

推理只接受 `/v1/messages`。调用方的 `system`、原生工具定义、`tool_choice`、`output_config.effort`、`metadata` 与内容块进入校验后，内部继续使用 Messages 表示。工具参数保持对象；工具结果使用 `user` 消息里的 `tool_result`，按实际工具 ID 验收。一个 user 消息里的多个工具结果会按原顺序拆为独立收据，续接时按需合并。

移除了 Chat Completions 路由，以及 `function.arguments` 字符串、`tool_calls`、`role: tool` 和第二套 token 用量统计。旧路径返回 404，旧请求字段（例如 `max_completion_tokens`、`stream_options`）返回 400。图片仅接受原生 `image` 的 base64 来源，旧 `image_url` 不再支持。

CLI 结果按原始相对顺序保留文本和已核验工具。对 `文本 A → 工具 → 文本 B`，JSON 与 SSE 都按该顺序交付；工具仍须完整校验，工具后面的文字会一同等待，避免提前发送而重排。用量只使用 `input_tokens`、`output_tokens`、`cache_read_input_tokens`、`cache_creation_input_tokens`，缓存用量不再加进输入 token 再重复报告。

这不是完整的官方 API 透传：系统指令仍由官方 CLI 承载，网关会移除系统文本块开头的 billing 传输行；客户端缓存元数据保留于入站结构，实际 CLI 缓存由现行策略控制，默认 1h。未支持的功能仍明确拒绝。

## 删除的旧入口

- OMP 导入、独立探测与云端客户端脚本，以及仅为它们使用的 YAML 依赖。
- FRP/STCP 配置、证书生成、启动服务、登录任务和旧状态诊断脚本。
- 无生产调用者的恢复种子生成函数和执行器热修复包装。
- 安装验收中的双协议分支；验收统一使用 Messages、临时回环服务和合成工具结果。

当前安装器、SSH 隧道、官方登录、CLI 更新器继续使用。自动更新器的验收参数同步为当前协议。服务名和已有部署 profile 命名保留，避免损坏现有安装。

## 仍有用途的设计

逐轮 CLI 和原生持久会话分别有独立生命周期与测试，仍保留。逐轮路径将历史编译成 CLI 可接受的输入；持久会话只续接新增消息。这两者是执行模式，不是两套公网协议。

工具核验、取消保护、拒绝传递、额度冷却、会话归档和诊断脱敏继续保留。系统/开发者动态指令和运行状态处理也保留，以支持已有调用方行为；正文中伪造的角色不能成为指令。模型别名继续用于已生成的客户端配置。

## 升级与验证范围

2.0 更改了内容块历史指纹与 MCP 名称（`mcp__caller__`），因此使用独立的 `native-session-index-v2`。先结束旧活动会话及等待中的工具，再更新服务并新建桌面会话。不会复制旧索引来伪造可恢复状态，也不会自动删除旧归档。回退旧程序时仍需停止新版活动会话。

本地回归使用合成 CLI、回环 HTTP、临时目录和离线测试，覆盖 JSON/SSE 混合块顺序、工具参数、工具结果、拒绝、用量、会话续接与旧接口拒绝。Windows 跳过的 Linux 专属用例由 Ubuntu CI 验证。代码测试通过不等于真实模型或 VPS 已验收；本轮不调用真实模型，也不部署服务。

## 审计修复

顶层系统规则与停止序列参与会话身份；缓存控制元数据不进入系统提示正文或身份。恢复尾部禁止追加工具收据，同 ID 重复结果不会覆盖原结果。控制提示采用严格纯文本视图，保留原始块，并拒绝混合工具或图片冒充控制指令。SSE 保活产生的纯空文本块只在历史指纹中规范化，非空正文、工具顺序和其他语义仍须匹配。

2.0.2 发布前复审修复了原生工具收据内自动记忆的读取位置：存活会话和持久检查点压缩都保留已核验的记忆，篡改内容或失败 Write 仍被拒绝。无效系统块返回 400，不再被当作上游故障。

升级时先备齐新程序，再替换受管理目录并清除已删除的旧入口；程序替换失败会回滚这一阶段；回滚本身失败时保留新旧程序现场并报告目录，供人工恢复。重跑从新的源码子目录解压，避免旧暂存目录污染。Node、配置及状态目录保持原位，其他安装阶段仍遵循 INSTALL.md 的故障恢复说明。CLI 隔离验收重新固定检查动态指令、历史原位引用与第二轮运行状态。
