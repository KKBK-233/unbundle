# Claude Code Relay

项目目前处于实验与整理阶段，尚未形成可直接安装、完整复现的公开版本。当前 `main` 分支仅保留状态说明，不提供可运行的程序、配置或安装脚本。

## 为什么现在不能直接使用

- **公开部署流程尚不完整。** 原有实现依赖事先准备的服务器环境、服务账户、固定目录，以及另行安装的 Node.js、frp 和官方 CLI；部署模板不能代替完整安装流程。
- **运行条件需要单独准备。** 登录状态、访问令牌、证书和私有部署配置不包含在仓库中。下载仓库不能直接获得可用服务。
- **兼容性仍在验证。** 已有实验覆盖部分请求和工具往返，但历史消息桥接、长会话表现及上游 CLI 升级兼容仍有边界，不能视为完整、稳定的协议实现。
- **发布准备尚未完成。** 文档、配置示例、项目命名和许可证仍需整理与确认，当前不作为正式版本发布。

后续完成整理与验证后，再更新正式使用说明。
